# Lumetta hotfix 2026-10-04

- Visible story is now always derived from canonical `story.text`, never from `voiceScript`.
- Expressive `voiceScript` is used for TTS only when its spoken words exactly match `story.text` after cue removal.
- All short bracketed performance cues, including aliases such as `[d]`, are removed from reading text.
- Live stories now always attempt `/image`; a stale cached `/health` result can no longer suppress cover generation after a Worker upgrade. Image failures still fall back safely.
- Existing About-page credits remain unchanged.
- Cloudflare Worker image request matches the current xAI `grok-imagine-image-2.0` API shape (`aspect_ratio`, `resolution`, `quality`, `response_format: b64_json`).
